---
name: Brand language
description: When to use the short Play Brain Games brand versus individual game names.
---

Use “Play Brain Games” as the short brand in general UI copy. Use the full “Play Brain Games . Online” form where the canonical site name is appropriate. Keep “Sudoku” and “Memory Match” in game-specific instructions, legal copy, and search metadata when the exact games matter.

**Why:** The user asked to replace repeated generic pairings of the two game names with the app’s brand/common name.

**How to apply:** Prefer the brand for general labels, tooltips, and umbrella descriptions; retain individual game names when they help a user understand a specific action or improve search relevance.

# Theme Background Images

Place images here named exactly as the colour-theme ID to use them as the background for that theme.

Supported formats (checked in this order): `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`

## Available theme IDs
light, dark, ocean, forest, sunset, midnight, rose, emerald, slate, lavender,
amber, teal, crimson, coral, arctic, mocha, neon, cyberpunk, deepsea, obsidian,
mint, peach, nordic, wine, superman, spiderman, batman, dora

## Example
- `light.jpg`  → used as background when the "Light" colour theme is active
- `ocean.png`  → used as background when the "Ocean" colour theme is active

If no file is found for the current theme, the app falls back to the built-in Unsplash default.
User-uploaded custom images (via the Themes page) always take priority over both.
